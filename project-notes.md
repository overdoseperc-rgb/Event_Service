# Project Notes

## Назначение

Event Service помогает организатору вести список мероприятий и регистрировать участников.

## Основные сущности

- мероприятие: идентификатор, название и дата;
- участник: имя и идентификатор мероприятия;
- регистрация: связь участника с мероприятием.

## Следующие этапы

В следующих практических работах проект получит Linux-окружение, Dockerfile, Docker Compose и полноценную архитектуру веб-сервиса.
