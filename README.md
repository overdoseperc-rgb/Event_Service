# Event Service

Проектная тема: сервис управления мероприятиями.

Event Service — учебный REST-сервис для создания мероприятий и учёта участников.

Проект будет развиваться в следующих практических работах:

```text
Git -> Linux -> Docker -> Docker Compose -> Архитектура -> Финальный проект
```

## Возможности

- создание мероприятия;
- просмотр списка мероприятий;
- регистрация участника;
- отмена регистрации;
- хранение данных в JSON-файле.

## Быстрый запуск

Требуется Python 3.10 или новее.

```bash
python -m app.cli list
python -m app.cli create "День открытых дверей" "2026-10-15"
python -m app.cli register 1 "Иван Петров"
```
