# Git Conflict

Во время работы специально создан конфликт между ветками `main` и `feature/project-description`.

## Причина

Обе ветки изменили одну и ту же строку описания проекта в `README.md`:

- в `main` проект назван учебным REST-сервисом;
- в `feature/project-description` сделан акцент на организации городских и учебных мероприятий.

Команда `git merge feature/project-description` остановила автоматическое объединение и добавила в файл конфликтные маркеры `<<<<<<<`, `=======` и `>>>>>>>`.

## Решение

Конфликт исправлен вручную. В итоговом тексте сохранён общий смысл обоих вариантов:

```text
Event Service — учебный REST-сервис для организации мероприятий и учёта участников.
```

После удаления конфликтных маркеров выполнены команды:

```bash
git add README.md
git commit -m "fix: resolve README merge conflict"
```

Коммит `fix: resolve README merge conflict` имеет двух родителей и подтверждает завершённый merge.
